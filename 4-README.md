# Plant Watering Tracker

Per-plant watering schedules with care notes, tags and progress photos.

- **Problem source**: [Reddit request (78 upvotes)](https://www.reddit.com/r/developersIndia/comments/1isvhnk/whats_your_i_wish_there_was_an_app_for_that/) — 30+ plants with different watering schedules, wanting custom schedules, observation notes, tags and progress pics.
- **Features**: per-plant interval schedules with due/overdue status, notes log (stressed, needs pruning, fertilizer...), tag filtering, progress photos with timeline, JSON export/import.
- **Run it**: open `index.html` in a browser, or use the GitHub Pages site.
- **Privacy**: everything stays on your device (localStorage for data, IndexedDB for photos). Photos are not included in JSON exports. No account, no upload.

Not included: AI plant identification (would need a paid service).
